MathML: Mass–Energy Equivalence

Einstein's mass–energy equivalence, written in MathML so the browser lays out the formula itself instead of showing a picture of it:

E = m c 2

E is energy, m is mass, and c is the speed of light.

Why MathML Support Came So Late

MathML became a W3C standard in 1998, and HTML5 lets you write <math> straight into a page. But a web feature is only practical once every major browser supports it, and for most of that time Chrome didn't. Here's the history according to Can I use:

  • Firefox supported MathML early, fully since Firefox 4 in 2011.
  • Safari had partial support starting with version 3.1, and full support from Safari 10 in 2016.
  • Chrome shipped MathML in version 24 in 2013, then removed it in version 25 because the implementation was unstable. It stayed out for about ten years.
  • Internet Explorer and the original Edge never supported it natively.
  • Chrome and Edge 109 finally added it in January 2023. They implement MathML Core, a smaller and more precisely defined part of MathML. Engineers at Igalia, an open-source consultancy, did much of that work rather than the Chrome team.

Chromium-based browsers make up most of the browser market, so for years developers couldn't count on native MathML. They used JavaScript libraries like MathJax and KaTeX to render equations, or just used images. The browsers that did support MathML also drew it differently from each other. That's part of why MathML Core exists: it spells out exactly how each element should lay out so every engine draws the same result. Since 2023, MathML works in every major browser, and Can I use lists it at about 96% global support.
