LectureFetch

LectureFetch is a Chrome extension that saves university lecture recordings as MP4 files, so students can rewatch lectures offline or on a slow connection. It works with Kaltura-based lecture players like UCSD Podcast and Canvas media. It's published on the Chrome Web Store, where it has nearly 100 users.

What I did

  • Designed and built the whole extension on Chrome's Manifest V3 platform, with a background service worker and a popup interface.
  • Used the webRequest API to watch network traffic while a lecture plays, pick out the video stream, and show a count badge on the toolbar icon when it finds one.
  • Built the popup that lists each stream it finds, including different quality options such as 720p and 1080p. Each stream has a Download button that saves it as an MP4.
  • Added a Settings option so users can add their own school's media domains.
  • Kept it private by design: everything runs on the user's computer, and no browsing data leaves the browser.

Built with JavaScript, HTML, CSS, and the Chrome Extensions APIs (webRequest, downloads, and storage).
